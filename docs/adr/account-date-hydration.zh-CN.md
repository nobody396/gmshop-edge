# 账户订单日期的水合一致性

账户总览和订单列表共用 OrderLink。原先订单日期分别依赖服务器和浏览器默认时区，跨时区首次加载会触发 React 418。

复用 TanStack Router 的 useHydrated：服务器和浏览器首次渲染统一使用 UTC，水合完成后继续显示原有的浏览器本地时间，保留当前语言。不改数据库时间戳、返利结算条件、全局格式化默认值，也不使用 suppressHydrationWarning 掩盖错误。

回归测试渲染真实 AccountOverviewPage，在另一默认时区水合同一份 HTML，要求 onRecoverableError 为空且最终文字仍为浏览器本地时间；覆盖中英文和纽约、上海时区。原失败差异为 2026-10-09 03:30:28 与 2026-10-08 23:30:28。不增加组件、依赖、上下文或持久偏好。
