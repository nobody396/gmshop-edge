# 老板订单通知去重

队列处理和定时任务可能同时读取同一条待发送事件，各自发送后才标记完成，造成重复通知。

发送前原子抢占现有 `next_attempt_at` 字段，租期两分钟，只有抢占成功者发送；完成、延后和重试均校验租约。租约使用实时钟，而非可能滞后的定时任务时间。进程中断后租约可过期恢复，无需新表、迁移或新队列。

飞书请求使用事件 ID 作为固定 `uuid`，补充覆盖飞书一小时去重窗口内的响应丢失；不宣称长时间故障后的无限期严格仅一次。其他飞书消息不传此可选参数，行为不变。

回归覆盖：三任务并发、有效/过期租约、发送失败重试和请求 UUID。集成测试从空 D1 应用全部迁移。验证不重放客户订单、不发送真实测试消息。

范围仅内部老板通知，不改客户邮件、支付、库存和交付。消融检查：复用现有调度字段和发送函数，不新增通用锁抽象或依赖。
